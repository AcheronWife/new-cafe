## 状态与领奖

- 任务组 5，任务进度位于 bit 1～31，bit 0 为已领奖；
- `41001` 的 bit 1～5 保存累计奖励领取状态；
- 登录时按当前 v1 业务状态单调投影进度，不覆盖领奖标记；
- `GuideMissionGetAward` 校验完成、未领取和前置任务已领取；
- `GuideProgressGetAward` 按完成任务数量校验 3/6/9/12/15；
- 奖励、任务值、背包、货币和少女变化在同一事务提交；
- 使用 `MissionMgrMsg nMission=3/4` 刷新客户端。

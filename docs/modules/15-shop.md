# 商店

## 当前完成度

**占位。** 只实现了让客户端接受的空商品列表。

## 已实现

`LuaCall sCmd=11` 读取 `shopid`，返回：

```text
shopid
isopen = 1
refreshcount = 0
goodslist = []
```

这些字段是客户端 `GoodsLogicC` 接受响应所需的最小结构。当前主要用于避免咖啡馆
流程请求商店时卡住。

## 验证

`test/shop-data.test.ts` 验证返回字段和值。没有设备购买流程或网关集成测试。

## 已知缺口

- 没有商品配置、库存、价格、限购和开放期；
- 没有购买、刷新、货币扣除和奖励发放；
- 商店状态不持久化；
- `shopid` 不校验，任意 ID 都返回开放的空商店；
- 不应把当前实现视为任何一个真实商店已经可用。
